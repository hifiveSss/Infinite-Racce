# Infinite Race — FREE Gemini AI + multiplayer website

A browser-only crafting/race game inspired by Infinite Craft. Players need no download and no API key. Host deploys the server once.

## Get a free Gemini API key (site owner only)
1. Open https://aistudio.google.com/app/apikey and sign in.
2. Create an API key in a **Free tier** project. **Do not enable paid billing.** Free access/limits depend on region and project; check the project's actual tier and quota.
3. On Render, in your Web Service > Environment, add `GEMINI_API_KEY` with the key value. Do not put it in the website HTML or public repository.
4. Optionally set `GEMINI_MODEL=gemini-2.5-flash-lite` (default). Check that this model supports free API requests in your account.
5. Render redeploys/restarts with the key. AI combinations are generated by Gemini, not OpenAI.

## Public website for players
1. Create a free GitHub repository and upload the *contents* of this folder (server.js, recipe-engine.js, package.json and public/index.html).
2. Open https://dashboard.render.com/ and create a **Web Service** connected to the repo.
3. Choose **Free**; build command `npm install`; start command `npm start`.
4. Share your Render website URL. Friends can open it in any browser, use lobby codes, and play without downloading or signing up.

Render Free sleeps after 15 minutes idle and takes time to wake. It may restart or erase saved local cache. Recipe cache is stored on the filesystem and **is not persistent on Render Free**. To keep all discoveries reliably across restarts, integrate a persistent database. Gemini's free tier has per-minute/day limits; unlimited free AI is not available. Never connect a paid billing account if zero cost is essential.

## How crafting works
Known recipes are handled immediately. Unknown combinations call Gemini server-side to return one meaningful word and a Unicode emoji. The server validates and caches each pair. The same pair yields the same result while its cache remains. When quota is exhausted it shows an error (not a nonsense word combination).

## Local development (optional, not required for players)
`npm install` then `npm start` (Node.js 18+). Add `GEMINI_API_KEY` to your shell environment to enable AI.
